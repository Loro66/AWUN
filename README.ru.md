# AWUN

> Музыкальное пространство, которое ищет композиции в подключённых каталогах, хранит библиотеку на устройстве и превращает твой вкус в бесконечную персональную станцию.

AWUN параллельно ищет музыку в YouTube, SoundCloud, Audius, Jamendo и Internet Archive. MusicBrainz расширяет запросы: использует альтернативные написания, транслитерацию, релизы и ISRC. Недоступность одного источника не ломает остальные результаты. SoundCloud HLS-потоки проходят через AWUN media proxy и воспроизводятся встроенным HLS.js.

## Что уже работает

- единый поиск с режимами `AUTO / CIS / EUROPE / USA / LATAM / ASIA / GLOBAL`;
- 30, 60 или 100 результатов и честное отображение отключённых источников;
- **MY WAVE** — бесконечная очередь со знакомым/новым, настроением, активностью, языком и эпохой;
- лайки, дизлайки и исключение артиста из будущих рекомендаций;
- локальная библиотека и импорт публичного плейлиста по ссылке;
- перенос CSV, JSON, M3U и TXT с автоматическим поиском проигрываемых совпадений;
- официальный YouTube Player, перемотка, повтор трека/очереди и Media Session;
- автоматическое переключение SoundCloud/YouTube/Audius при сбое с сохранением позиции — только если найдено близкое совпадение по названию, артисту и длительности;
- настоящая локальная очередь: «Играть следующим», добавление в конец, удаление, перетаскивание и сохранение между запусками;
- тексты LRCLIB, Genius-аннотации при наличии серверного токена и личные комментарии к строкам;
- шесть тем, минимальный режим и адаптивный интерфейс с единой версионированной точкой входа CSS, токенами темы и фиксированным порядком каскада;
- web/PWA, автономная Windows-версия, Android-сборка для Google Play и iOS beta.

## Попробовать и установить

- **Web / PWA:** открой [awun-1.onrender.com](https://awun-1.onrender.com). В Chrome или Edge нажми **INSTALL APP** — AWUN появится в меню «Пуск», на рабочем столе или домашнем экране телефона.
- **Windows:** скачай артефакт `AWUN-Windows-x64` в [Windows desktop builds](https://github.com/Loro66/AWUN/actions/workflows/build-windows-exe.yml). Текущая сборка содержит интерфейс и FastAPI внутри EXE, запускает случайный локальный адрес `127.0.0.1` и по умолчанию использует публичный backend AWUN с локальным backend как резервом. Интернет для поиска и воспроизведения всё равно требуется. Бета пока не подписана коммерческим сертификатом, поэтому SmartScreen может показать предупреждение.
- **Android / Google Play:** версия 1.8 подготовлена как `com.loro66.awun`, использует API 36, собирается в подписанный AAB и не показывает скачивание музыки. Карточка магазина, privacy/Data safety и точный чек-лист находятся в [`mobile/android/play-store/`](mobile/android/play-store/RELEASE_CHECKLIST.md). Владелец Play Console должен отдельно настроить ключ загрузки и пройти обязательное тестирование.
- **iOS beta:** инструкции и воспроизводимая неподписанная сборка находятся в [`mobile/`](mobile/README.md). Для установки на физический iPhone нужна подпись Apple.

## Быстрый запуск сервера

Нужен Python 3.11 или новее.

```bash
git clone https://github.com/Loro66/AWUN.git
cd AWUN
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.api.main:app --reload
```

Открой `http://127.0.0.1:8000/`, документация API находится в `/docs`. Для YouTube рекомендуется задать `AWUN_YOUTUBE_API_KEY`; остальные переменные описаны в [README.md](README.md#configuration) и [.env.example](.env.example).

## Важные ограничения

AWUN не является VPN и не обходит региональные или провайдерские ограничения. Он не открывает приватные библиотеки без официальной авторизации, не снимает DRM и не превращает потоковые плейлисты в «скачанные MP3». Кнопка скачивания появляется только когда источник действительно разрешает получить публичный файл.

Для сети, где провайдер блокирует отдельные источники, Windows-версия по
умолчанию использует уже существующий публичный backend AWUN
(`https://awun-1.onrender.com`). Это бесплатный Render-сервис: новый сервер,
аккаунт и ручная настройка не нужны. Бесплатный сервис может засыпать после
простоя, поэтому первый запрос после паузы иногда занимает около минуты.
Если endpoint временно недоступен, приложение автоматически повторяет запрос
через локальный backend.

Если нужен другой endpoint, укажи
`AWUN_REMOTE_API_URL=https://твой-домен` перед запуском или запиши HTTPS-адрес
одной строкой в `%APPDATA%\\AWUN\\remote-api.txt`. Значение `local` принудительно
оставляет запросы локальными. Не используй неизвестные IP из чужих hosts-файлов:
это прокси неизвестного владельца, который может перехватывать трафик.
YouTube остаётся официальным embedded player и может требовать отдельный
сетевой доступ или Zapret.

Проект бесплатный. Пожертвования поддерживают разработку и серверы, но не продают музыку, доступ к каталогам или защищённые загрузки. Подробности — в [SUPPORT.md](SUPPORT.md#русский).

кодом**, а не open-source проект. Официальную неизменённую сборку можно

## Технологии

Python 3.11+, FastAPI, aiohttp, Pydantic, yt-dlp, Web Audio/Media Session, pywebview, GitHub Actions.

Интерфейс, динамические сообщения, ошибки поиска, настройки, импорт, плеер и «Моя волна» полностью переведены на русский; английский можно включить кнопкой языка. Техническая документация, API и условия запуска подробно описаны в [английском README](README.md). Ошибки и предложения можно оставить в [Issues](https://github.com/Loro66/AWUN/issues).
