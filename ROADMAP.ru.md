# Дорожная карта AWUN

[Обзор проекта](README.ru.md) · [English](ROADMAP.md) · [Справка о проекте](docs/PROJECT_CASE_STUDY.ru.md)

В дорожной карте используются критерии готовности, а не неподтверждённые сроки. Завершённая инженерная работа отделена от пользовательской проверки, которой ещё не было.

## Готовый фундамент

- Публичная веб-бета, установщик Windows и portable EXE с версионным релизом.
- Local-first backend для Windows с удалённым резервом на уровне отдельного источника.
- Постепенный поиск, постоянная очередь и восстановление воспроизведения.
- Локальная медиатека, сигналы «Моей волны», резервная копия и проверяемое восстановление.
- 233 Python-теста и 26 Playwright-сценариев в обязательных GitHub Actions.

## Сейчас: проверить продукт на людях

Цель: заменить предположения об удобстве на прослеживаемые наблюдения.

- Провести один сценарий из пяти заданий как минимум с тремя согласившимися участниками.
- Для каждого задания записать выполнение, время, блокирующие ошибки и вопросы участника.
- На каждую воспроизводимую проблему открыть GitHub Issue и связать его с исправляющим коммитом.
- Публиковать только агрегированные результаты без личных запросов и данных участников.

Критерий готовности: каждая блокирующая проблема исправлена и проверена либо явно записана как ограничение.

## Далее: сделать Windows-дистрибуцию доверенной

- Добавить Authenticode-подпись с проверяемым издателем.
- Описать обновление и откат установленной версии.
- Добавить smoke-проверку релиза на чистой Windows-системе.
- Измерять доступность публичного сервиса и задержку отдельных источников без сбора истории прослушивания.

Критерий готовности: на чистом Windows-компьютере можно проверить файл, установить, запустить, обновить и удалить AWUN по документированному сценарию.

## Затем: проверить мобильную дистрибуцию

- Завершить закрытое Android-тестирование с Play signing и проверкой деклараций магазина.
- Убедиться, что Play-клиент не показывает запрещённые кнопки скачивания.
- Проверить жизненный цикл, media controls и восстановление локальных данных на физических устройствах.
- Считать iOS экспериментальным до появления Apple-подписи и тестов на реальном устройстве.

Критерий готовности: Android-пакет проходит закрытое тестирование, а все заявления о данных совпадают с наблюдаемым сетевым и локальным поведением.
