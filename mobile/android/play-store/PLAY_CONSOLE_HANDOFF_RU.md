# AWUN 1.8.0 — финальный ввод в Google Play Console

Этот лист предназначен для первого релиза пакета `com.loro66.awun`. Он не
заменяет проверку фактического поведения опубликованной сборки и требований,
которые Play Console покажет владельцу аккаунта.

## Сначала: владелец и приложение

- Владелец личного Play Console должен быть совершеннолетним и использовать
  настоящие данные. Если основателю ещё нет 18 лет, аккаунт регистрирует и
  подтверждает родитель, опекун или другой доверенный совершеннолетний владелец.
- Создать **Приложение**, язык по умолчанию **Русский (ru-RU)**, название
  **AWUN — поиск музыки**, тип **Приложение**, распространение **Бесплатно**.
- Условия разработчика и Play App Signing принимает только владелец аккаунта.
- После загрузки первого AAB навсегда проверить package name:
  `com.loro66.awun`.

## Карточка приложения

Все тексты лежат в `mobile/android/fastlane/metadata/android`.

| Поле | Русский файл | Английский файл |
|---|---|---|
| Название | `ru-RU/title.txt` | `en-US/title.txt` |
| Краткое описание | `ru-RU/short_description.txt` | `en-US/short_description.txt` |
| Полное описание | `ru-RU/full_description.txt` | `en-US/full_description.txt` |
| Примечания к версии | `ru-RU/changelogs/18000.txt` | `en-US/changelogs/18000.txt` |

Для каждой локали загрузить:

- `images/icon.png` — 512×512;
- `images/featureGraphic.png` — 1024×500;
- четыре файла из `images/phoneScreenshots` — 1080×1920.

Категория: **Музыка и аудио**. Публичный канал поддержки:
`https://github.com/Loro66/AWUN/issues`. Рекомендуемый сайт после восстановления сервера:
`https://awun-1.onrender.com/support`.

## Data safety

- Приложение собирает **историю поиска в приложении**: да, передаётся серверу,
  обрабатывается временно, обязательна только для выбранной пользователем
  функции поиска, цель — **Функциональность приложения**, не хранится в базе.
- **Другой пользовательский контент**: публичная ссылка на плейлист — да,
  временная обработка, необязательно, цель — **Функциональность приложения**.
- Продажа данных, реклама, аккаунты, платежи, аналитические и рекламные SDK: нет.
- Передача шифруется по HTTPS. Удалённого аккаунта нет; локальные данные
  удаляются в AWUN, через **Очистить хранилище** Android или удалением приложения.
- Перед отправкой сверить полный лист `DATA_SAFETY.md` с реально развёрнутым
  сервером и всеми включёнными источниками.

## Загрузка и тестирование

1. Включить Play App Signing и загрузить подписанный
   `AWUN-1.8.0-18000-signed.aab` во **Внутреннее тестирование**.
2. Добавить русские и английские примечания к версии.
3. Установить сборку из Google Play на физический Android и проверить поиск,
   воспроизведение, сохранение, «Мою волну», поворот, фон, офлайн-ошибку,
   поддержку и конфиденциальность.
4. Исправить все ошибки Pre-launch report и предупреждения Policy status.
5. Если это новый личный аккаунт, провести закрытый тест с минимум 12
   подключёнными тестировщиками непрерывно 14 дней и только затем запросить
   доступ к production.
6. Для production включить Managed publishing и начать с поэтапного выпуска.

Нельзя нажимать отправку на проверку, пока `/`, `/health`, `/privacy`,
`/support`, `/license` и `/eula` не отвечают HTTP 200 без входа.
