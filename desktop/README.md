# AWUN Desktop 1.8 Local

Windows-версия AWUN больше не открывает сайт Render. `AWUN.exe` содержит
интерфейс, FastAPI и адаптеры источников. При запуске приложение:

1. выбирает свободный случайный порт на `127.0.0.1`;
2. запускает локальный backend внутри процесса AWUN;
3. открывает встроенный русский интерфейс через Microsoft Edge WebView2;
4. отправляет поисковые запросы к музыкальным источникам с компьютера
   пользователя;
5. останавливает локальный сервер при закрытии окна.

Render и работающий сайт для Windows-приложения не нужны. Полностью офлайн
приложение работать не может: для поиска и воспроизведения требуется интернет.
Медиатека, настройки и профиль «Моей волны» сохраняются в
`%APPDATA%\\AWUN\\desktop-state.json`, поэтому случайный порт при следующем
запуске не сбрасывает данные.
Ключи API можно передать через обычные переменные `AWUN_*`; они не вшиваются в
общедоступный EXE.

## Опциональный режим сетевой совместимости Windows

Desktop-сборка может включить отдельный режим совместимости для сетей, где
SoundCloud или YouTube недоступны из-за DPI-фильтрации. Кнопка
`СОВМЕСТИМОСТЬ` появляется только в desktop-интерфейсе.

Это не VPN: режим не создаёт туннель, не отправляет весь трафик через чужой
сервер и не меняет публичный IP-адрес. Поэтому он не способен исправить
серверное geo-IP ограничение самого музыкального сервиса. Он предназначен
только для случаев, где соединение режется или замедляется DPI на пути до
сервиса.

При первом включении AWUN:

1. читает последний релиз `Flowseal/zapret-discord-youtube` через GitHub API;
2. скачивает ZIP релиза и требует опубликованный GitHub SHA256;
3. проверяет содержимое архива и его SHA256;
4. показывает стандартный запрос UAC Windows;
5. elevated-процесс ещё раз копирует архив в защищённый каталог и повторно
   проверяет SHA256;
6. устанавливает Flowseal/winws в
   `%ProgramFiles%\\AWUN\\RegionalCompat` и создаёт службу
   `AWUNRegionCompat`;
7. фильтрует только узкие hostlist SoundCloud и YouTube. Broad IPSet и игровой
   фильтр не используются.

WinDivert является сетевым драйвером и может отмечаться антивирусами как
risk tool. AWUN не скрывает этот факт и не отключает антивирус автоматически.
При выключении режима AWUN удаляет свою службу и каталог
`%ProgramFiles%\\AWUN\\RegionalCompat`.

Если на компьютере уже запущена отдельная служба `zapret`, AWUN не запускает
второй фильтр поверх неё, чтобы не создавать конфликт. В таком случае сначала
нужно отключить внешний zapret либо настроить необходимые домены в нём.

Работоспособность DPI-стратегии зависит от провайдера и может меняться. Первый
вариант AWUN использует узкую адаптацию текущей default-стратегии Flowseal;
если конкретная сеть требует ALT-стратегию, это должно добавляться как
отдельный профиль, а не через перехват всего трафика компьютера.

Flowseal/bol-van распространяются по MIT, а включённый в их релизы WinDivert
имеет собственные LGPLv3/GPLv2 условия. AWUN скачивает оригинальный релиз и
сохраняет его `LICENSE.txt` рядом с бинарниками.

## Сборка

На Windows 10 или 11 запусти `build-windows.bat`. Готовые файлы появятся в
`dist\\`: `AWUN.exe`, контрольная сумма SHA256, лицензия и пользовательское
соглашение. Значок из `desktop\\assets\\awun.ico` встраивается через
`AWUN.spec`.

GitHub Actions перед упаковкой запускает desktop-тесты, а затем создаёт сборку.
Открой **Actions → Windows desktop build → Run workflow** или скачай артефакт
`AWUN-Windows-x64` из завершённого запуска. Теги `v*` публикуют файлы в GitHub
Releases.
