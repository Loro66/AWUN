# SONGVALE Desktop

Windows-версия SONGVALE содержит
интерфейс, FastAPI и адаптеры источников. При запуске приложение:

1. выбирает свободный случайный порт на `127.0.0.1`;
2. запускает локальный backend внутри процесса SONGVALE;
3. открывает встроенный русский интерфейс через Microsoft Edge WebView2;
4. сначала отправляет запросы к источникам через локальный backend;
5. использует публичный backend только для источника, который не ответил локально;
6. останавливает локальный сервер при выходе из приложения.

Новый сервер для Windows-приложения не нужен. Полностью офлайн приложение
работать не может: для поиска и воспроизведения требуется интернет.
Медиатека, настройки и профиль «Моей волны» сохраняются в
`%APPDATA%\\SONGVALE\\desktop-state.json`, поэтому случайный порт при следующем
запуске не сбрасывает данные. При первом запуске SONGVALE автоматически читает
состояние из прежнего каталога `%APPDATA%\\AWUN`, если нового файла ещё нет.
Ключи API можно передать через обычные переменные `AWUN_*`; они не вшиваются в
общедоступный EXE.

## Работа из сети с региональными ограничениями

Для сети с блокировками desktop-версия сначала использует встроенный локальный
backend. Если конкретный источник вернул ошибку, SONGVALE повторяет только его через
публичный backend `https://awun-1.onrender.com`. Новый сервер и ручная настройка
не нужны. Бесплатный Render может засыпать, но его запуск не задерживает ответы
исправных локальных источников.

Чтобы выбрать другой endpoint, укажи его origin в переменной
`SONGVALE_REMOTE_API_URL` или запиши одну строку с адресом в
`%APPDATA%\\SONGVALE\\remote-api.txt`, например:

```text
https://music.example.net
```

После перезапуска `SONGVALE.exe` этот endpoint станет резервным, а не основным.
Прежняя переменная `AWUN_REMOTE_API_URL` также поддерживается для совместимости.
Значение `local` полностью отключает remote-маршрут. Используй только endpoint,
которым ты управляешь или которому
доверяешь. HLS.js встроен в desktop-сборку, а SONGVALE proxy переписывает ссылки
на сегменты SoundCloud, поэтому браузер не обращается к CDN SoundCloud напрямую.
SONGVALE не подставляет IP неизвестных прокси и не снимает
географические ограничения лицензированных сервисов. YouTube по-прежнему
воспроизводится официальным embedded player и может требовать Zapret или другой
сетевой доступ отдельно.

На Windows 10 или 11 запусти `build-windows.bat`. Готовые файлы появятся в
`dist\\`: `SONGVALE.exe`, контрольная сумма SHA256, лицензия и пользовательское
соглашение. Значок из `desktop\\assets\\songvale.ico` встраивается через
`AWUN.spec`.

GitHub Actions создаёт такую же сборку. Открой
**Actions → Windows desktop build → Run workflow** или скачай артефакт
`SONGVALE-Windows-x64` из завершённого запуска. Теги `v*` публикуют файлы в GitHub
Releases.

## Мини-плеер, трей и горячие клавиши

Кнопка мини-плеера переключает текущее окно в компактный режим поверх других окон.
Возврат: «Полное окно», Escape или Ctrl+Alt+M. Позиция и аудиопоток сохраняются.
Для YouTube остаётся видимый официальный плеер.

Значок в трее открывает меню воспроизведения и выхода. В настройках Windows можно
выключить закрытие в трей и глобальные сочетания. Если значок не создан, окно
закрывается обычным образом. Ctrl+Alt+Space — пауза, Left/Right — треки,
Up/Down — громкость, M — мини-плеер, S — показать окно. Занятые сочетания
показываются в настройках; keyboard hooks не используются.

## Обновление в один клик

Настройки → Управление Windows → «Обновить в один клик». Приложение проверяет
стабильный релиз Loro66/AWUN, скачивает установщик и его SHA-256, проверяет размер
и контрольную сумму и сохраняет медиатеку перед запуском установки. Установщик
обновляет каталог текущего EXE и запускает новую версию. Сбой скачивания или
проверки оставляет текущую версию работающей. С версий ниже 2.6.0 нужно сначала
установить актуальный EXE вручную; начиная с 2.6.0 используется кнопка обновления.
