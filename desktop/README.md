# AWUN Desktop

Windows-версия AWUN содержит
интерфейс, FastAPI и адаптеры источников. При запуске приложение:

1. выбирает свободный случайный порт на `127.0.0.1`;
2. запускает локальный backend внутри процесса AWUN;
3. открывает встроенный русский интерфейс через Microsoft Edge WebView2;
4. сначала отправляет запросы к источникам через локальный backend;
5. использует публичный backend только для источника, который не ответил локально;
6. останавливает локальный сервер при закрытии окна.

Новый сервер для Windows-приложения не нужен. Полностью офлайн приложение
работать не может: для поиска и воспроизведения требуется интернет.
Медиатека, настройки и профиль «Моей волны» сохраняются в
`%APPDATA%\\AWUN\\desktop-state.json`, поэтому случайный порт при следующем
запуске не сбрасывает данные.
Ключи API можно передать через обычные переменные `AWUN_*`; они не вшиваются в
общедоступный EXE.

## Работа из сети с региональными ограничениями

Для сети с блокировками desktop-версия сначала использует встроенный локальный
backend. Если конкретный источник вернул ошибку, AWUN повторяет только его через
публичный backend `https://awun-1.onrender.com`. Новый сервер и ручная настройка
не нужны. Бесплатный Render может засыпать, но его запуск не задерживает ответы
исправных локальных источников.

Чтобы выбрать другой endpoint, укажи его origin в переменной
`AWUN_REMOTE_API_URL` или запиши одну строку с адресом в
`%APPDATA%\\AWUN\\remote-api.txt`, например:

```text
https://music.example.net
```

После перезапуска `AWUN.exe` этот endpoint станет резервным, а не основным.
Значение `local` полностью отключает remote-маршрут. Используй только endpoint,
которым ты управляешь или которому
доверяешь. HLS.js встроен в desktop-сборку, а AWUN proxy переписывает ссылки
на сегменты SoundCloud, поэтому браузер не обращается к CDN SoundCloud напрямую.
AWUN не подставляет IP неизвестных прокси и не снимает
географические ограничения лицензированных сервисов. YouTube по-прежнему
воспроизводится официальным embedded player и может требовать Zapret или другой
сетевой доступ отдельно.

На Windows 10 или 11 запусти `build-windows.bat`. Готовые файлы появятся в
`dist\\`: `AWUN.exe`, контрольная сумма SHA256, лицензия и пользовательское
соглашение. Значок из `desktop\\assets\\awun.ico` встраивается через
`AWUN.spec`.

GitHub Actions создаёт такую же сборку. Открой
**Actions → Windows desktop build → Run workflow** или скачай артефакт
`AWUN-Windows-x64` из завершённого запуска. Теги `v*` публикуют файлы в GitHub
Releases.
