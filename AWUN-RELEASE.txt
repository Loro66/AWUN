SONGVALE 2.5.3
Release date: 2026-10-01

This release adds named playlists and faster navigation through a personal library.

What changed:
- Create up to 25 local playlists, each containing up to 1000 tracks, and add
  recordings from search results without losing them when removing a favorite.
- Filter your saved tracks or a playlist by artist and title without waiting for
  another online search. Open recent playlists directly from the home hub.
- Imported file, text and public-link collections keep a named playlist in the
  original order. Interrupted transfers and manual picks can continue it.
- Playlist data is included in local backup exports and validated on restore.
- Storage failures are shown instead of silently accepting unsaved changes.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after Python, frontend and browser tests pass on
GitHub Actions.
