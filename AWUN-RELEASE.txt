SONGVALE 2.5.2
Release date: 2026-09-30

This release improves library transfer, source settings and search reliability.

What changed:
- The home hub adapts to the saved library, recent tracks and searches.
- Search starts without waiting for a delayed source status check.
- Selected search sources survive a restart.
- The transfer reads Russian CSV headers, quoted fields and copied track lists.
- Files over 1000 tracks are reported instead of silently truncated; matching
  progress and interrupted sessions remain visible.
- Mobile hub labels are easier to read and shuffle has a larger touch target.
- HLS media reads are bounded and media DNS resolution rejects private targets.
- Docker defaults to one worker; multiple workers require AWUN_MEDIA_SECRET.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after Python, frontend and browser tests pass on
GitHub Actions.
