SONGVALE 2.5.14
Release date: 2026-10-07

This release fixes library matching, repeated manual review and expired SoundCloud playback links.

What changed:
- Library transfer finds popular recordings without waiting for a slow source.
- Artist credits, Topic channels and official-video labels no longer hide matches.
- Provider failures have their own status and can be retried after a reload.
- Manual review cannot resurrect a selected track while a transfer is running.
  Repeated entries are reviewed once; alternate recordings stay separate.
- SoundCloud playback checks the real CDN expiry and refreshes stale links
  without reusing expired search-cache results. Direct audio and HLS use their
  appropriate player paths.
- Backup and cloud safety from 2.5.11 remain in place.
- Accounts are available after the host has configured a persistent
  Supabase project, the SQL schema and custom email delivery, then enabled
  the feature flag. Until then the app remains in guest mode.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after Python, frontend and browser tests pass on
GitHub Actions.
