SONGVALE 2.5.10
Release date: 2026-10-03

This release refreshes the SONGVALE identity across the website and app icons,
alongside clear playback and My Wave progress states.

What changed:
- The sidebar now has a distinct valley mark and SONGVALE wordmark without the
  unreadable tagline. The same mark appears on iPhone, Android and web icons.
- Restoring a full backup while signed in pauses cloud sync and asks whether to
  combine libraries, keep the cloud copy, or explicitly replace it.
- A failed cloud replacement remains pending after a reload.
- My Wave starts with short discovery searches, then widens empty results, waits
  for connected fallback sources, and keeps existing music playing when no new
  tracks are found.
- The player says when a track is loading, looking for another source or
  unavailable. Play retries a failed track.
- My Wave shows search attempts, distinguishes empty results from source errors,
  and stops retrying after a bounded search. Retry and setting changes can start
  a new search.
- Accounts are available after the host has configured a persistent
  Supabase project, the SQL schema and custom email delivery, then enabled
  the feature flag. Until then the app remains in guest mode.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after Python, frontend and browser tests pass on
GitHub Actions.
