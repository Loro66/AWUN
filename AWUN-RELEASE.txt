SONGVALE 2.5.11
Release date: 2026-10-03

This release protects cloud libraries when restoring or transferring backups.

What changed:
- A library file can replace a guest library, but an account-linked library
  can only be combined with the file. This remains true when the account
  service is temporarily unavailable.
- A restored full backup offers Combine or Use account copy. Cloud-only music
  survives a backup merge, including after a failed sync and retry.
- The account screens explain what will happen before importing a library.
- Accounts are available after the host has configured a persistent
  Supabase project, the SQL schema and custom email delivery, then enabled
  the feature flag. Until then the app remains in guest mode.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after Python, frontend and browser tests pass on
GitHub Actions.
