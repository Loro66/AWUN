SONGVALE 2.5.5
Release date: 2026-10-02

This release moves language selection into Settings and prepares optional
cross-device accounts.

What changed:
- The language control now lives in Settings, freeing the sidebar.
- Optional email accounts have sign-up, sign-in, password recovery, sign-out, deletion and
  revision-checked favorites/playlist sync with guest-library review.
- Stream URLs, listening history and taste signals remain device-local.
- Accounts are available after the host has configured a persistent
  Supabase project, the SQL schema and custom email delivery, then enabled
  the feature flag. Until then the
  app remains in guest mode and does not claim that libraries are syncing.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after Python, frontend and browser tests pass on
GitHub Actions.
