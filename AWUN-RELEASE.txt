AWUN 1.10.5
Release date: 2026-09-11

Release highlights:
- Deliver the frontend CSS as one cached, precompressed response instead of an
  import waterfall.
- Load the HLS player only when a SoundCloud stream needs it.
- Stop idle playback polling, forced layout reads and full-viewport decorative
  animation.
- Update queue rows in place and handle queue actions through one event listener.
- Reuse fresh stream URLs for 20 minutes while preserving stale-link recovery.
- Search sparse aliases concurrently and reuse track fingerprints during deduplication.
- Remove an unused 349 KB image from the packaged frontend.

The Windows application bundles FastAPI and the complete frontend and starts on
an ephemeral loopback port. Search still uses the local API first, and playback
still retries stale provider links. This release reduces startup requests,
unnecessary DOM work and background timers without removing user-facing
features.

The automated release gate contains 237 Python tests. The repository also keeps
26 Playwright scenarios for desktop, tablet and phone layouts.

The Windows archive includes AWUN.exe (portable), AWUN-Setup-x64.exe (per-user
installer), their SHA-256 checksums, LICENSE.md and EULA.md. Extract the archive
fully before running either application.
