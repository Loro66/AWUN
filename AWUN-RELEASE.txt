SONGVALE 2.5.6
Release date: 2026-10-03

This release adds a visible profile and portable library transfer, and improves
account synchronization and the installed web app's recovery from slow hosting.

What changed:
- An account profile can show and edit a display name.
- Favorites and playlists can be exported and imported between devices even
  when account service is not configured. Imports offer combine or replace.
- Account writes retry after network failures, detect lost acknowledgements,
  and accept optional null metadata returned by music sources. Sign-out clears
  the account view in other open tabs.
- The installed web app opens a cached shell when a slow or failing host cannot
  serve a fresh page promptly.
- Stream URLs, passwords, listening history and taste signals are excluded from
  portable library files.
- Accounts are available after the host has configured a persistent
  Supabase project, the SQL schema and custom email delivery, then enabled
  the feature flag. Until then the app remains in guest mode.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after Python, frontend and browser tests pass on
GitHub Actions.
