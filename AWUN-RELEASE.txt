SONGVALE 2.5.4
Release date: 2026-10-03

This release makes SONGVALE installable and easier to launch on iPhone.

What changed:
- Open the hosted app in iPhone Safari and use Share > Add to Home Screen.
- The installed web app starts from its cached interface during server wake-up
  or temporary network loss; music and search still require a connection.
- Localized installation instructions show on iPhone and disappear in installed
  mode. The service worker excludes API responses and audio/video from cache.
- Account and cross-device sync requirements are recorded for the next stage.
  Favorites and playlists are still stored on each device in this release.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after Python, frontend and browser tests pass on
GitHub Actions.
