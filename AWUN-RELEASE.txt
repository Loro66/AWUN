SONGVALE 2.2.0
Release date: 2026-09-16

This release turns the persistent player into a focused listening dock that
feels deliberate on desktop, compact windows and phones.

What changed:
- Reorganized the player into clear track, transport, timeline and utility
  zones instead of one oversized waveform strip.
- Reduced visual noise, empty spacing and control scatter while preserving the
  waveform as part of SONGVALE's identity.
- Added compact previous, play, next and repeat controls with consistent hit
  areas and stronger active states.
- Kept save/remove-from-library and queue controls visible across supported
  viewport sizes.
- Hid secondary volume and expansion tools only where narrow mobile layouts
  would otherwise become cramped.
- Updated all reviewed desktop, compact and mobile visual baselines.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after the complete Python suite and all 28
browser behavior/responsive scenarios pass on GitHub Actions.
