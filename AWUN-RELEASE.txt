SONGVALE 2.1.2
Release date: 2026-09-16

This release repairs text-based library transfer for lists copied directly
from music catalog pages.

What changed:
- A copied playlist row is now parsed as one track: title, one or more artist
  lines, and duration.
- Duration values such as 02:40 are ignored as metadata instead of being sent
  to search as fake track titles.
- Multiple artist lines remain attached to the same track.
- The importer no longer turns a small copied library into dozens of invalid
  searches and misleading "not found" results.
- Added a browser regression test for the exact multiline format that exposed
  the problem.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after the complete Python suite and all 28
browser behavior/responsive scenarios pass on GitHub Actions.
