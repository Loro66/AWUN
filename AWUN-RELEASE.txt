SONGVALE 2.5.13
Release date: 2026-10-04

This release improves public playlist transfer and carries forward the new SONGVALE identity.

What changed:
- Public playlist import now counts distinct tracks toward its limit. Repeated
  entries no longer hide later songs, and available links and cover art survive
  deduplication.
- The generic V has been replaced by a forest silhouette over a winding orange
  river. The matching angular wordmark remains clear without a tiny tagline.
- The new mark appears in the website header, PWA and browser icons, iPhone,
  Android and Windows icons, and Google Play artwork.
- Backup and cloud safety from 2.5.11 remain in place.
- Accounts are available after the host has configured a persistent
  Supabase project, the SQL schema and custom email delivery, then enabled
  the feature flag. Until then the app remains in guest mode.

Windows package:
- SONGVALE-Setup-x64.exe — per-user installer.
- SONGVALE.exe — portable executable.
- Separate SHA-256 checksum files, LICENSE.md and EULA.md.

The release is published only after Python, frontend and browser tests pass on
GitHub Actions.
