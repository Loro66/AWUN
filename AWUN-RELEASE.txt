SONGVALE 2.0.0
Release date: 2026-09-11

Release highlights:
- Rename the product from AWUN to SONGVALE throughout the application.
- Add an original five-pillar sound-valley logo and a forest/orange visual identity.
- Replace the old display type with a cleaner geometric system wordmark.
- Embed the new icon in the web app, PWA, Windows executable and installer,
  Android launcher and iOS shell.
- Preserve existing libraries and settings through legacy storage and backup
  compatibility.
- Add SONGVALE desktop state and remote-API configuration with migration from
  the previous AWUN locations.

The Windows application still bundles FastAPI and the complete frontend and
starts on an ephemeral loopback port. Search remains local-first and provider
fallback behavior is unchanged by the rebrand.

The automated release gate contains the Python suite and the repository keeps
Playwright scenarios for desktop, tablet and phone layouts.

The Windows archive includes SONGVALE.exe (portable), SONGVALE-Setup-x64.exe
(per-user installer), their SHA-256 checksums, LICENSE.md and EULA.md.
